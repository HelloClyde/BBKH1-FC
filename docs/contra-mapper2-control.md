# 魂斗罗 Mapper 2：0.1.14 普通版完整应用对照

本次用用户提供的魂斗罗 ROM，检查其第一关在当前核心中的执行成本。
这是实际普通 BDA 的 MIPS 指令计数，不是物理 H1 帧率测试。

| 对象 | SHA-256 |
| --- | --- |
| 0.1.14 普通 BDA | `ad8989bc948052b2fe8c452c201188ba6cf9903c287c6321417a61a4290f2235` |
| 魂斗罗 ROM，Mapper 2、128 KiB PRG、CHR RAM | `26541a5550ee22deeb3d5484e4a96130219b58cff74d068fb1eb6567fa5e5519` |

设置为跳帧 1、缩放 1、声音开启、音量 100。通过固件输入队列在第 301 帧按 Start，
随后移动、射击和跳跃。截图检查确认第 900、960、1140、1200 帧均已进入第一关丛林；
统计范围为 **901–1200，共 300 帧**。较早的标题与关卡过场探索不计入游戏性能结果。

完整应用运行 1200 帧，包含加载、游戏、暂停菜单与正常退出，执行 **3,248,230,694** 条
MIPS 指令。独立普通计数与只读函数普查重放的全部 1200 帧画面、PCM、CPU/PPU、
声明状态、呈现标记和每帧指令量严格一致；完整 PCM、播放环、最终画面和应用日志也一致。
两次均正常退出，音频接口错误与欠载为零；固件服务由测试器模拟，这不证明真机音频流畅度。

## 第一关成本

300 帧共 **828,823,378** 条指令，平均 **2,762,745 条/帧**；实际显示 150 帧，
产生 110,059 帧源 PCM。下表为函数自身的独占指令成本，不重复计入其调用的其他函数。

| 函数 | 指令量 | 窗口占比 |
| --- | ---: | ---: |
| `h1_cpu_run_interpreter` | 279,911,157 | 33.77% |
| `FCEU_SoundCPUHook` | 166,009,653 | 20.03% |
| `RefreshLineBody` | 108,379,783 | 13.08% |
| `RdMemNorm` | 67,696,953 | 8.17% |
| `FCEUPPU_Loop` | 39,028,102 | 4.71% |
| `RDoTriangleNoisePCMLQ` | 35,409,854 | 4.27% |
| `scale_nes_indexed_rgb32` | 35,294,780 | 4.26% |
| `memcpy` | 29,687,713 | 3.58% |
| `SexyFilter` | 9,259,956 | 1.12% |
| `RDoSQLQ` | 6,965,874 | 0.84% |

`FCEU_SoundCPUHook` 包含 CPU 时钟推进、APU/DMC 事件检查及处理，**不能把这 20.03%
全部称为声音合成**。三角波、噪声、DMC 与方波的实际混音工作分别出现在表中的 LQ 函数。

## 与三国志2城市段比较

两项均执行同一 0.1.14 普通 BDA，使用上述相同设置，范围包含应用的核心、显示和音频工作。

| 场景 | 范围 | 指令量 | 每帧平均 | CPU 执行路径 |
| --- | --- | ---: | ---: | --- |
| 魂斗罗第一关 | 901–1200 | 828,823,378 | 2,762,745 | 解释器 |
| 三国志2城市 | 1501–1800 | 661,217,984 | 2,204,060 | JIT 与解释器回退 |

魂斗罗日志为 `JIT_OPEN ready=0 reason=mapper_policy mapper=2 fallback=interpreter`，
窗口内全部 JIT 计数增量为零。魂斗罗指令量比三国志2城市多 **25.35%**，这个结果既不能
推出魂斗罗在真机更慢，也不能把两款游戏的差异归因于 Mapper 19：游戏逻辑、画面内容、
访存方式和 CPU 执行路径均不同，没有隔离 Mapper 这一变量。

MIPS 指令条数不等于实际时钟周期；缓存、分支、访存与固件服务耗时未由本测试测出。
生成代码局部性可能影响实际运行，但本次没有证明缓存是瓶颈。下一步应在同一台 H1、
相同设置及明确场景下记录实际周期或墙钟时间，再核对持续音频欠载和显示节奏。
