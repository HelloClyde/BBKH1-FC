# 0.1.10：执行区间、PPU 与基础声音合成

本轮基线为 0.1.9 默认 4 MiB 的正式 BDA，SHA-256：
`12ca8c6d937c3e37cd2061810dc542a1b20849f92d68a6d5afe5e53479ddca1c`。
保留 bank 复用、原生 PCM 播放、存档校验及游戏按键行为。

## 默认设置

首次运行和显示菜单“恢复默认”使用跳帧 1，每两帧显示一帧。
已有有效配置中的用户选择继续保留。跳帧只控制画面输出，CPU、APU、
PPU 可观察状态和游戏逻辑仍逐帧推进，声音采样率和音量不变。

## 优化边界

- 执行区间：完整 CPU 预算足够且不会跨越硬件事件时，整段一次准入，
  集中提交预算、时钟和可延后的状态。短 CPU 时间片保留精确前缀执行。
  用 APU、DMC 和 Namco IRQ 的最早事件边界截取安全前缀，避免只因整段
  不能完成就退化成一次执行一条指令。可观察的 IO 和不透明回调保留同步边界。
- 块入口：首次进入仍逐字节检查代码和读取/写入处理函数；同一有效区间再次进入或
  原生块相连时，允许复用有版本号的验证结果。无特殊 PPU/输入钩子、无 overclock 的
  NROM/Namco 普通帧可跨 CPU 短时间片复用。映射、处理函数、代码缓存变化、IRQ/NMI
  和不透明回调撤销凭据；纯内存解释器指令和已核对的 APU 事件可保留凭据。
  不透明回调后重新检查帧内准入，避免临时安装的 PPU 钩子穿透验证。
  外部直接调用的公开原生入口保持严格检查，快速入口仅供内部协议使用。
  待执行 DMC DMA 的非批量指令在计时前交回解释器，避免回调改动当前操作数后仍使用旧值。
  音频事件刚产生新 DMA 请求时，只补完已经计时的当前指令再返回调度；
  分支及跨页附加周期保留，不重复计时或提前取数。
  没有 PPU/输入钩子时，按地址和原始函数指针识别 $2000–$2006 写入，
  保留其代码凭据与事件期限，包括 OAM DMA 的 $2004 目的写。
  DMA 源读取仍逐次核对处理函数；$2007 的 VRAM 写入及未知处理函数不在白名单内。
  原生调用期间固定代码池生命周期，回调递归 CPU 时允许追加编译，但推迟会
  覆盖活跃返回地址的缓存回收；公开入口、私有入口及块连接使用同一保护。
- C 回退调度：把 Mapper IRQ 和 APU 时钟合为一次事件期限判断，在已准入的
  普通帧内供 C 和原生执行交替使用。缓存 Namco IRQ 的启用模式，普通路径
  不再重复辨认 Mapper 回调。每条指令按原顺序推进 IRQ、APU 帧和 DMC 计数。
  期限不晚于三个事件的最早边界；帧计数用保守的移位计算避免除法，提前到期时
  只重新检查实际计数，不提前发送事件。真正到期仍调用原始处理函数。
  不透明回调前后、真实声音事件、帧边界，以及未重新验证的 PPU/输入钩子变化
  均使期限失效；时间戳回绕使用有符号距离比较。回调留下尚未提交的 DMA 周期时
  不授予新期限，避免把已经推进的时间戳误当作 APU 时间。
  C 回退仍有廉价的逐指令期限检查；整段一次准入用于已证明安全的原生指令区间。
- 正常显示 PPU：仅对没有 Mapper/HD 等回调的普通图块区间批处理。
  在一次区间内复用 fine-X、移位状态、nametable 行地址和相邻图块共享的
  属性值。CPU 同步边界后重新取得 CHR 映射、调色板和滚动状态，
  不跨边界缓存这些输入。精灵零判断和有观察者的路径保留原语义。
- 基础 APU：方波、三角波、噪声及 DMC DAC 混合按输出恒定区间累计。
  区间在 PCM 输出桶边界、振荡器/LFSR 变化和本次寄存器刷新边界停止，
  保留整型 PCM、相位及事件顺序。DMC 取数、DMA 占用和 IRQ 不被音频合成优化省略。

## 比较方法

相同《三国志 II》ROM、1800 帧新游戏/城市命令脚本、音量和声音设置，
分别比较跳帧 0 和跳帧 1。两版均通过正常文件读取加载相同 CRC 配置，
不通过改写客体状态实现测试设置。默认设置变化与相同工作量下的优化收益分开报告。

完整应用包含启动、编译、CPU/PPU/APU、显示、音频供给、存档、菜单与退出。
逐帧比较画面、源 PCM 和声明状态，并比较播放环、显示节奏及存档载荷。
完整序列化差分和事件边界专项另外验证。

MIPS 指令量描述软件执行成本，不是物理 H1 的时钟周期或帧率。
固件服务 mock 的音频消费节奏不能证明真机已经没有欠载。
ROM、固件、截图和音频留在本地测试目录，不进入安装包。

## 旧版城市阶段的成本

对固定 0.1.9 的第 1501–1800 帧补充只读函数计数，全部 1800 帧的
状态、PCM、画面及显示节奏与既有缓存一致；300 帧的每帧指令量也逐项相同，
合计 1,033,027,437 条。以下为互不重叠的函数自身成本：

| 部分 | 指令量占比 |
| --- | ---: |
| PPU 背景处理 RefreshLineBody | 23.81% |
| C CPU/JIT 调度 h1_cpu_run_jit | 16.40% |
| 生成的 MIPS 代码 | 16.39% |
| indexed 缩放 | 11.62% |
| PPU 主循环 | 10.83% |
| memcpy | 6.67% |
| 方波合成 | 2.50% |
| 三角波、噪声、DMC DAC 合成 | 2.43% |

APU 的两个合成函数不包含全部声音开销，C CPU/JIT 调度也不等同于纯调度开销。
这些占比来自正常显示为主的模拟城市流程，不替代真机严重欠载时的跳帧场景。
先前失败的动态 hook 计数被弃用；修正后清除的是 Unicorn 宿主翻译缓存，
没有改变客体的 JIT 缓存。每帧计数一致性检查用于防止漏记已有翻译块。

## 最终完整应用结果

正式版 SHA-256：`ecb0e11debb7f16df9b7b191c27e427e6f7b2a59563eea9121244a1572884315`，
诊断版：`acec402362dc0ef55b98ebcefd3288300d661c8ec315ba161d0122a0e7dff803`。
两版均在独立输出目录重建，产物逐字一致。

| 相同显示设置 | 0.1.9 完整流程指令量 | 0.1.10 完整流程指令量 | 整段减少 | 城市命令阶段减少 |
| --- | ---: | ---: | ---: | ---: |
| 跳帧 0 | 6,014,025,065 | 5,658,552,312 | 5.91% | 5.30% |
| 跳帧 1 | 4,772,340,422 | 4,558,758,989 | 4.48% | 3.64% |

城市命令阶段为第 1501–1800 帧，指令量分别为 1,033,027,437 → 978,299,874（跳帧 0）、
811,000,120 → 781,491,748（跳帧 1）。截图已核对城市选择、并州刘备菜单和资源/命令页。
两组各 1800 帧的画面、源 PCM、声明状态、播放环、存档和显示节奏严格一致。
PCM 均为 660,352 帧；跳帧 0 / 1 分别显示 1740 / 886 帧，同组前后相同。
默认跳帧变化带来的少绘制收益没有计入上表。

同一份 PPU/APU/JIT 实现下，单独启用合并事件调度，跳帧 1 全流程从
4,560,814,069 减为 4,558,758,989，净减少约 **0.045%**；城市段约增加 **0.022%**，
基本持平。调度统一消除了重复分类和重复到期检查，但不是本轮主要收益来源。
32 帧精灵+DMC IRQ 合成压力场景从 110,159,787 增至 111,436,449（增加 **1.16%**），
完整序列化状态、画面和 PCM 仍一致；不能把三国志 II 的收益推广到全部游戏。

本流程实际代码占用 4,538,880 字节，8 MiB 代码池没有回收。
连同入口、bank 和凭据表实际申请 9,865,247 字节，约 9.41 MiB；分配失败回退解释器。
代码池扩容与执行路径优化一起计入本版对照，不把整体收益归因于单个优化。

## 验证与范围

- 实际 MIPS 指令差分覆盖 87 类指令/2809 例、寻址 451 例、连续运行 782 例、完整状态 144 例。
- 事件边界 232 例、区间调度 274 例、组合 C 时钟 155 例，以及动态帧钩子和待提交 DMA。
- 版本凭据 41 例及 6 个完整帧、PPU 边界 40 例、递归原生调用 10 例。
- 8 / 4 / 1 MiB bank 缓存各 930 个边界和 32 完整帧；8 / 4 MiB 活跃代码池各 6 例。
- APU 1186 项逐样本和状态差分，默认跳帧、PAL/NTSC、音频队列、慢显示、暂停、退出和存档回归。
- 最终普通版与诊断版均在完整 V1.41 固件模拟器验证有声运行、暂停恢复、关于页和退出回桌面。
  固件测试覆盖标题/菜单；城市流程由上面的完整应用测试覆盖。诊断版 TCU 校准正常，fault=0。
  Profile 离线日志读取器遇到部分使用 NAND 单元时失败，保留原失败证据后通过只读恢复核实
  全部连续日志与正常退出；这是测试读取器的限制。原始固件 494 个文件的 SHA 均未改变。

以上不是物理 H1 实测，尚不能据此保证全速或消除实际设备的音频欠载。
