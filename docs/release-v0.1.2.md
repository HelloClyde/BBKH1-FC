# H1 FC v0.1.2

作者：**HelloClyde**。首次公开预发布，适用于步步高 H1 / Y100 V1.41。

## 本版变化

- 暂停菜单“关于”显示作者 HelloClyde、版本、模拟核心及致谢，触摸和实体键均可进入和返回。
- 菜单字体采用 Noto Sans CJK SC，提供 OFL 1.1 许可、固定来源及可复现字形生成工具。
- 保留透明图标、选择器取消后返回桌面，以及暂停菜单确认键不会误触游戏 Start 的修复。
- 独立 SDK / FCEUmm 子模块、固定 MIPS 工具链、GitHub Actions 与完整源码发布包。

## 下载与安装

`BBKH1-FC-v0.1.2-install.zip`：将 `应用`、`FC` 文件夹合并到设备 A 盘。
程序路径为 `A:\应用\程序\H1FC.bda`，游戏目录为 `A:\FC\`。
包内仅附原创测试卡带 `H1FC-TEST.nes`，自己的游戏通过原生选择器打开。
`H1FC.bda` 是同一构建的单独应用文件；`BBKH1-FC-v0.1.2-source.zip` 包含应用和两个固定子模块的全部源码。
`SHA256SUMS.txt` 用于核对下载文件，`release-manifest.json` 记录构建及验证身份。

正式 BDA：**952,216 字节**，SHA-256：

`4deadc5370616567191f3e90fa174feb88f69890e11a3c812a8b4af8bbce5634`

SDK：`067fe072477861dfc8949d7b1a55279fb92d2548`；
FCEUmm：`ac0d00a7fc01166f84c7bac01d1084ebfd2b865e`。

## 验证范围

- 主机平台回归及实际 MIPS BDA 的 12 项完整测试：画面、按键、PCM、存档恢复、中文路径、
  无电池卡带、同名换卡隔离、损坏存档、非法／截断／过大 ROM 和不支持 mapper 均通过。
- 正式 BDA 的三槽即时存档、暂停 CPU/RAM 冻结、坏槽保护与 PCM 复用通过。
- 完整 H1 V1.41 固件／QEMU 中运行 From Below 1.0 Classic：移动、旋转、硬降、声音、暂停恢复、
  触摸与实体键进入“关于”、正常退出均通过，记录 1,476 帧、0 个视频错误。
- 空 FC 目录不选 ROM，连续两次取消均恢复桌面且可重新打开；不初始化核心或声音。
- 图标透明通道、BDA/ZIP 一致性和干净源码重建由发布检查核对；CI 另执行真实 MIPS 服务替身测试。
